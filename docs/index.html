Anime Companion

A chat you can talk to about any anime. It acts like a friend who has seen the whole show — but it will never spoil anything past where you are, and you don’t have to tell it which episode you’re on. It figures out where you are from what you say.

How the no-spoiler logic works

  1. You pick a show and just start chatting — no episode number needed.
  2. Each message, it infers your furthest point (mapping any scene or arc you mention to its episode) — conservatively, only moving forward.
  3. It then answers with a spoiler-gated prompt: it’s told your current episode and forbidden from revealing, hinting at, or even foreshadowing anything beyond it.

Run it on your machine

git clone https://github.com/ayehills/Btc-tracker
cd Btc-tracker
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...      # from console.anthropic.com
python app.py                            # open http://localhost:5000

Or chat in the terminal: python anime_companion.py "Jujutsu Kaisen"

Under the hood

Built on Claude (Opus 4.8) via the official Anthropic SDK, with a Flask chat backend and live anime metadata (episode counts, synopsis) from the free Jikan / MyAnimeList API. Your API key stays in your environment.

This page is just an info card — the companion itself is a local app (it needs a Python backend and your own Anthropic API key, so it can’t run on GitHub Pages). See the repository to get started.
